# 블록 쌓기

브라우저에서 바로 실행되는 간단한 블록 낙하 퍼즐 게임(MVP)입니다.
HTML/CSS/JavaScript만 사용하며, 설치하거나 빌드할 것이 없습니다.
화면은 Material Design 3 스타일이고(시스템 설정에 따라 라이트/다크 테마 자동 전환), 배경음악은 Web Audio API로 직접 합성해 재생합니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 랜딩 페이지 (게임 소개, 플레이 방법, 플레이 버튼) |
| `game.html` | 게임 화면 (게임 보드, 점수 패널, 모바일용 조작 버튼) |
| `style.css` | Material Design 3 스타일 (랜딩·게임 공용, 반응형) |
| `game.js` | 게임 로직 |
| `music.js` | 배경음악 (러시아 민요 "코로베이니키", Web Audio API 합성) |

> 글꼴(Roboto)은 Google Fonts에서 불러옵니다. 인터넷에 연결되어 있지 않으면 시스템 기본 글꼴로 표시되며, 게임은 그대로 동작합니다.

## 실행 방법

### 방법 1. 파일을 바로 열기 (가장 간단)

`index.html`을 더블클릭하거나 브라우저 창에 끌어다 놓으면 랜딩 페이지가 열립니다.
**지금 플레이** 버튼을 누르면 게임 화면(`game.html`)으로 이동합니다. `game.html`을 바로 열어도 됩니다.

### 방법 2. 로컬 웹 서버로 실행

프로젝트 폴더에서 아래 명령 중 하나를 실행합니다.

```bash
# Python 3
python3 -m http.server 8000

# Node.js가 설치되어 있다면
npx serve -l 8000
```

그다음 브라우저에서 아래 주소로 접속합니다.

```
http://localhost:8000            # 랜딩 페이지
http://localhost:8000/game.html  # 게임 화면 바로 열기
```

서버를 끄려면 터미널에서 `Ctrl + C`를 누르세요.

> **WSL 사용 시:** WSL 안에서 서버를 실행해도 Windows 브라우저에서 `http://localhost:8000`으로 접속할 수 있습니다.
> 파일을 직접 열려면 Windows 탐색기 주소창에 `\\wsl$\`을 입력해 프로젝트 폴더를 찾은 뒤 `index.html`을 여세요.

### 같은 네트워크의 다른 기기에서 접속하기

방법 2로 서버를 실행한 뒤, 같은 Wi-Fi에 연결된 휴대폰이나 다른 PC에서 `http://<실행한 PC의 IP 주소>:8000`으로 접속합니다.
(방화벽에서 8000번 포트를 허용해야 할 수 있습니다.)
휴대폰에서도 화면 아래에 조작 버튼이 나타나 바로 플레이할 수 있습니다.

## 게임 방법

1. **시작하기** 버튼을 누릅니다.
2. 떨어지는 블록을 움직이고 회전시켜 가로줄을 빈칸 없이 채우면 그 줄이 지워지고 점수를 얻습니다.
3. 블록이 맨 위까지 쌓이면 게임 오버입니다. **다시 시작** 버튼으로 새 게임을 시작합니다.

### 조작법

| 키 | 동작 |
| --- | --- |
| `←` `→` | 좌우 이동 |
| `↓` | 빠르게 내리기 (칸당 +1점) |
| `↑` 또는 `X` | 회전 |
| `Space` | 바로 떨어뜨리기 (칸당 +2점) |
| `P` | 일시정지 / 계속하기 |
| `M` | 배경음악 켜기 / 끄기 |

상단 바의 음표 버튼과 일시정지 버튼으로도 같은 기능을 쓸 수 있습니다.

### 모바일 조작

터치 화면 기기에서는 보드 아래에 조작 버튼이 표시됩니다.

| 버튼 | 동작 |
| --- | --- |
| ‹ › | 좌우 이동 (누르고 있으면 계속 이동) |
| ⌄ | 빠르게 내리기 (누르고 있으면 계속) |
| ⟳ (큰 버튼) | 회전 |
| ⇊ | 바로 떨어뜨리기 |

다른 앱이나 탭으로 전환하면 게임이 자동으로 일시정지됩니다.

### 배경음악

- 브라우저 자동 재생 정책 때문에 **시작하기** 버튼을 누른 뒤부터 음악이 나옵니다.
- 일시정지하면 음악도 멈추고, 계속하면 멈춘 곳부터 이어서 재생됩니다.
- 레벨이 오를수록 음악 템포도 조금씩 빨라집니다.
- 음악 켜기/끄기 설정은 브라우저에 저장되어 다음 접속 때도 유지됩니다.

### 점수와 레벨

- 한 번에 지운 줄 수: 1줄 100점, 2줄 300점, 3줄 500점, 4줄 800점 (× 현재 레벨)
- 10줄을 지울 때마다 레벨이 오르고 블록이 더 빨리 떨어집니다.
